Entry for the make.fun bounty [The Production Database Apology](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a).

`main.py` (Python stdlib only) writes one line to `/output/entry.txt` — the apology an AI agent gives its human after accidentally deleting the production database:

> Sorry, I deleted the production database. I did make a backup first, though: it's stored safely inside the production database.

Deterministic: two runs produce byte-identical output.
